## Contracts and hand-offs

- **Session → list:** `TranscriptList(configuration, send, contentPadding, jumpRequest, onShowsJumpButtonChanged, slots)` (or `TranscriptView(store)` with `TranscriptFeature.State.configuration`). Build entries with `TranscriptEntry.build(items, isRunning, models, sessionStartModels)`; map every `TranscriptAction` to the iOS `SessionFeature.Action` of the same name (`OpenFile` → media viewer, `PreviewImage` → zoom viewer).
- **Moved down into this module:** `TranscriptSubagent`, `SessionLinkTarget`, `NewMessagesPlacement`/`NewMessagesMark`. `AgentFileReference` and `SessionLink`'s URL/ID half live in `:server` (the transcript keeps `mark`/`markRuns`/`marked`/`ids` as extensions); `TranscriptMetrics`, `TranscriptImagePreview`, `LinkMenuAction` and the link-preview value types live in `:feature:media`, which renders with them.
- **Slots `:feature:session` fills:** `TranscriptSlots.workingLine` (WorkingLineRow + orb), `LocalTranscriptRowSlots` (`agentGlyph`, `providerMark`). The reply end draws `LinkPreviewReplyEnd` itself.
- **Media:** rows render media directly (Mermaid card, image gallery, file cards, link previews, site icons). The list owns one `LinkPreviewStore` per session (remembered, closed on dispose) and provides it as `LocalLinkPreviewStore`, with `LocalLinkPreviewRevision`/`LocalLinkPreviewRow` per row. The highlighter is media's `SyntaxHighlighter`.
- **`:app` root:** wrap the app in `TranscriptMediaProviders { … }` so the file viewer renders Markdown files with the transcript's renderer (media's `LocalAgentFileMarkdown`).
- **`:app`:** install `EventBatcherHooks.withMarkdownStream()` at the root (`DependencyValues.installRoot { this[EventBatcherHooks] = this[EventBatcherHooks].withMarkdownStream() }`).
